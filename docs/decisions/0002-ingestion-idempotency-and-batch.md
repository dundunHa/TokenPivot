# ADR-0002：逐项批量结果与稳定事件身份

状态：已确认，关联 T-001。

## 决策

批次逐项独立事务；仅最终请求用量。身份为 `(workspace_id,source_id,source_event_id)`。source 是稳定插件实例，凭证轮换不改变它。规范化业务内容同则 duplicate，不同则 conflict，不允许静默覆盖。接收时间和传输 JSON 顺序不参与业务内容比较。

每条首次接受的原始事件与分钟增量同事务提交；失败整体回滚该条。accepted 只在提交后返回，批次中断后允许原 ID 重试。结果区分 accepted、duplicate、永久拒绝（含 conflict/expired）和可重试失败；具体HTTP格式由OpenAPI定义。

## 备选

整批回滚事务简单，但一个坏项会阻碍补报；选择逐项结果。允许覆盖更新可处理后续修正，却需要增减旧桶和版本竞争；首版不接受修正，避免隐式覆盖。

## 期限

先校验发生时间在过去180天内；超期返回expired，不承诺duplicate/conflict。明细防重依据保留首次接收后180天，详见 [ADR-0003](0003-minute-aggregation-and-retention.md)。ID不得复用，客户端不得修改时间绕过窗口。

## 后果与重新评估

插件需保留稳定身份并仅重试可重试项。来源不具备请求级最终用量时，先报告不支持，不能伪造请求；需要更正或汇总来源时重新设计格式与聚合语义。以后改变事件身份或规范化哈希代价高，必须版本化迁移。

验收：并发重复、批内重复、断响应、混合批次、冲突、凭证轮换、跨workspace同ID、超期重传。参见 [数据模型](../data-model.md)。
