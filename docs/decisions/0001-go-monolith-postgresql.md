# ADR-0001：Go 单体、PostgreSQL 与独立前端工程

状态：已确认，关联 T-001。

## 背景

官方 SaaS 和用户自托管共用核心服务；每日约10万事件，尚无本项目性能基准。前端需要独立开发和发布。

## 备选与决策

选择 Go 单体 + PostgreSQL，不选分析集群和外部队列：当前没有实测瓶颈支撑额外组件的运维成本。模块按业务分工，不预建可插拔存储框架。

选择独立 `web/` React 工程，而非把前端源代码与 Go 混写。自托管可内嵌构建产物；云端可独立静态托管，但浏览器仍通过同源入口访问 `/api`。不选择首版跨源 Cookie 支持。

## 后果与改变代价

独立工程保留构建自由；内嵌简化自托管分发。独立发布必须维护接口版本兼容与资源缓存。以后换静态托管成本低，拆服务或迁移统计数据库成本高，需要真实负载证明。

## 重新评估条件

在已确认机器、事件量、维度基数及查询并发下，同步摄入或查询无法达标，再讨论异步或分析数据库；不以参考项目组件数量作依据。
