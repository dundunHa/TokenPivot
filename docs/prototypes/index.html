说明

这些是原型，不是成品

三版都是单文件静态 HTML（无外部依赖，双击即开）。正式应用会用 React + TypeScript + shadcn/ui + Tailwind 重做，这里的 CSS 只用于确定视觉方向，不会直接搬进项目。

数据全部是示例

数字由固定公式生成，每次打开一致，用来检验排版和图表观感。它们不来自任何真实采集，也不代表产品已有的能力。

参考站核验还没做完

原计划从 Mobbin 与 21st.dev 取样定基调，但这两个域名在当前代理环境下解析到非公网地址，抓取失败。所以这三版是原创布局探索，没有对照过这两个站的具体模板。需要的话可以在能打开它们的网络环境里补一轮取色与版式对照。

E 即刻风已搁置

E 是上一轮的方向（不套卡片、只靠字号和留白），因为不是「极客风」而搁置，文件保留在 dashboard-e.html，可以对照。正式方向以 F 为准。

三版共用的信息结构

总量 → 趋势 → 维度排名（项目/模型/供应商）→ 请求明细。A/B/C 是自适应宽度，D 与 F 是 1920×1080 固定画布、随屏幕等比缩放。选版只改视觉层，不动这个骨架。
